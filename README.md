# Smart Banking Portal

A full-stack banking system prototype developed during my internship at **Bank Alfalah (IT Department)** under the supervision of my project mentor.  
The portal simulates **core banking operations** such as account management, secure transactions, and reporting dashboards, providing an enterprise-like experience in a learning environment.

---

## ✨ Features
- **User Authentication** – Secure login and session handling.
- **Account Management** – Create, view, and manage customer accounts.
- **Transaction Processing** – Deposit, withdrawal, and funds transfer.
- **Transaction Dashboard** – Interactive charts and reports using Recharts.
- **Data Management** – SQL Server (SSMS) for persistent storage and queries.
- **Secure Architecture** – Backend implemented with C# .NET (Clean Architecture).

---

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Recharts  
- **Backend:** C# .NET (Clean Architecture)  
- **Database:** SQL Server (SSMS)  
- **Tools:** GitHub, Visual Studio, VS Code  

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (for frontend)  
- [.NET 6+ SDK](https://dotnet.microsoft.com/) (for backend)  
- [SQL Server](https://www.microsoft.com/sql-server)  

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/smart-banking-portal.git
   cd smart-banking-portal

2. **Backend Setup**
   cd backend
   dotnet restore
   dotnet run

3. **Frontend Setup**
   cd banking-ui
   npm install
   npm start

4. **Database**
   Import the provided SQL scripts into SQL Server.
   Update the appsettings.json (backend) with your DB connection string.
